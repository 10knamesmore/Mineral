# Mineral 配置指南

默认配置文件为 `~/.config/mineral/config.lua`

## 基本规则

```bash
mineral config init    # init lua lsp things
mineral config check   # validate
```

- `default.lua` 是同目录生成的完整默认值参考,**程序不读它**,改它无效

### 生效方式

| 改动                                                             | 生效                                                                               |
| ---------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| `tui.theme` / `tui.keys` / `tui.behavior`、顶层脚本              | **保存即热重载**                                                                   |
| 其余 `tui.*`(动画时长 / 布局 / 频谱 / 封面…)                     | 重启 TUI                                                                           |
| `audio` / `cache` / `download` / `sources` / `daemon` / `script` | 重启 daemon(默认退出 TUI 会带走自拉起的 daemon,重开即生效;daemon 续命时需手动重启) |

### 环境变量(优先于配置文件)

| 变量                            | 覆盖                     |
| ------------------------------- | ------------------------ |
| `MINERAL_AUDIO_NULL=1`          | `audio.backend = "null"` |
| `MINERAL_SOCKET_DIR=<绝对路径>` | IPC socket 目录          |

## tui.theme — 主题色板

每个 token 可以是固定色 `"#rrggbb"`、终端 ANSI 槽或终端默认——写法详见下方[色值写法](#色值写法)。

| token      | 默认      | 生效位置                          |
| ---------- | --------- | --------------------------------- |
| `base`     | `#1e1e2e` | 主背景                            |
| `mantle`   | `#181825` | 次背景:嵌套面板 / 浮层底          |
| `crust`    | `#11111b` | 第三背景:底部 transport 条        |
| `surface0` | `#313244` | 行选中背景 / 进度条轨道           |
| `surface1` | `#45475a` | 未聚焦边框 / 分隔线               |
| `overlay`  | `#6c7086` | 暗淡文本 / 二级标签               |
| `subtext`  | `#a6adc8` | 三级文本 / metadata               |
| `text`     | `#cdd6f4` | 主文本                            |
| `accent`   | `#cba6f7` | 主强调:选中 / 聚焦边框 / 在播标记 |
| `accent_2` | `#74c7ec` | 副强调:进度条填充 / 频谱顶段      |
| `red`      | `#f38ba8` | 错误 / 删除 / love 标记           |
| `yellow`   | `#f9e2af` | 暂停指示                          |
| `green`    | `#a6e3a1` | 播放指示                          |
| `peach`    | `#fab387` | 命令 / 搜索前缀                   |

`search_hit` 是搜索命中字符的高亮样式:

| 字段        | 默认                              | 说明                                                                                                      |
| ----------- | --------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `color`     | `"peach"`                         | 14 个 token 名之一,或任意[色值写法](#色值写法)                                                            |
| `modifiers` | `["bold", "underline", "italic"]` | 叠加的字体效果,数组**整体替换**;可选 `bold` / `italic` / `underline` / `dim` / `reversed` / `crossed_out` |

`dynamic` 子表是封面驱动的动态主题, 随着正在播放歌曲运行kmeans取色

| 字段      | 默认   | 说明                                         |
| --------- | ------ | -------------------------------------------- |
| `enabled` | `true` | 关闭即恒用静态 `accent` / `accent_2`         |
| `fade_ms` | `3000` | 切歌 / 封面就绪后 accent 渐变过去的时长,毫秒 |

`text_alpha` 子表是文本层级的不透明度(0-1)

| 字段     | 默认 | 说明                                                     |
| -------- | ---- | -------------------------------------------------------- |
| `strong` | 0.78 | 次级文本:metadata / 面板标题 / 时间戳(≈ `subtext`)       |
| `muted`  | 0.45 | 暗淡标签:按键提示 / 别名后缀(≈ `overlay`)                |
| `faint`  | 0.22 | 弱线条:未聚焦边框 / 已缓冲轨道(≈ `surface1`)             |
| `ghost`  | 0.01 | 近背景:歌词远端淡出终点 / 空槽,近乎隐没(回落 `surface0`) |

### 色值写法

一个色值有四种写法:

| 写法                                 | 含义                       |
| ------------------------------------ | -------------------------- |
| `"#rrggbb"`                          | 固定rgb(必须带 `#`)        |
| `{ hex = "#rrggbb" }`                | (结构化写法,同上)          |
| `{ ansi = "blue" }` / `{ ansi = 4 }` | 引用终端 16 个 ANSI 槽之一 |
| `{ reset = true }`                   | 终端默认前景 / 背景        |

ANSI 槽名(或 `0`–`15` 编号):`black` `red` `green` `yellow` `blue` `magenta` `cyan` `white`(0–7)、`bright_black` … `bright_white`(8–15)。

> `search_hit.color` / 来源徽标色除以上写法外,还能直接写 token 名(如 `"peach"`)引用某个主题 token

### Recipe:跟随终端配色

让**背景层**跟随终端当前配色(换终端主题界面底色跟着变、与编辑器 / tmux 同色),**强调层**保留固定色:

```lua
theme = {
  -- 背景层:跟随终端
  base     = { reset = true },          -- 主背景用终端默认背景
  mantle   = { ansi = "black" },        -- 嵌套面板底
  crust    = { ansi = "black" },        -- transport 条
  surface0 = { ansi = "bright_black" }, -- 行选中底
  surface1 = { ansi = "bright_black" }, -- 未聚焦边框
  -- 其余 token(accent / accent_2 / red / green / …)不写 = 沿用默认固定色
}
```

### Recipe

```lua
-- ~/.config/mineral/themes.lua —— 返回一张表,每套 14 个 token
return {
  tokyonight = { base = "#1a1b26", accent = "#bb9af7", --[[ …其余 12 个… ]] },
  gruvbox    = { base = "#282828", accent = "#fabd2f", --[[ … ]] },
  -- 也可混固定色与跟随终端:
  follow     = { base = { reset = true }, accent = { ansi = "magenta" }, --[[ … ]] },
}
```

```lua
-- ~/.config/mineral/config.lua
local THEMES = dofile((os.getenv("HOME") or "") .. "/.config/mineral/themes.lua")

-- 每次配置加载随机挑一套
math.randomseed(os.time())
local pool = { "tokyonight", "gruvbox", "follow" } -- 想参与随机的名字
local chosen = THEMES[pool[math.random(#pool)]]

return {
  tui = { theme = chosen },
}
```

## tui.keys — 键位重映射

- 单字符键:`"j"`、`"/"`、`"+"`;**区分大小写**,`"J"` = `Shift+j`

- 值可以是单键或键数组:`activate = { "l", "<CR>" }`(数组**整体替换**默认绑定)

## tui.waveform — 进度条波形

播放进度条显示全曲波形，已播放的部分用颜色区分。

daemon 从完整音频文件计算波形数据并保存，支持本地、已缓存和已下载的歌曲。数据未就绪时显示普通进度条。流式播放的歌曲下载完整后也会计算；如果仍在播放，收到数据后就显示波形。下载完成前切歌不会使用不完整的文件。

| 字段          | 默认   | 说明                                                                                 |
| ------------- | ------ | ------------------------------------------------------------------------------------ |
| `enabled`     | `true` | 显示波形；数据未就绪时显示普通进度条                                                 |
| `cover_color` | `true` | 已播放部分使用封面颜色；`false` 时使用主题 `accent`                                  |
| `contrast`    | `2.0`  | 波形高度的 gamma；1 为线性                                                           |
| `edge_radius` | `3`    | 已播放与未播放部分的颜色过渡半径，列；0 为硬边，分界处表示当前进度，不额外高亮播放头 |

`reveal` 控制波形出现时的动画：从左向右展开，每列从底部升到目标高度，尚未展开的位置仍显示普通进度条。每首歌只播放一次动画，重复收到波形数据、快进退或暂停都不会重播。

| 字段          | 默认 | 说明                                                                                 |
| ------------- | ---- | ------------------------------------------------------------------------------------ |
| `duration_ms` | 560  | 动画总时长;`0` = 一帧到位(等同关闭)                                                  |
| `sweep_ratio` | 0.62 | 从左到右展开占总时长的比例，余下为每列升高的时间；1 为只横向展开，0 为所有列同时升高 |
| `glow`        | 0.85 | 展开处的提亮强度，0–1；向主题 `text` 混色，完成后恢复原色；0 关闭                    |

### Recipe:只在全屏时显示波形

用 `mineral.observe` 监听全屏状态，再用 `mineral.config.override` 切换波形开关：

```lua
local WAVEFORM_DEFAULT = false

mineral.observe("terminal", function(t)
  local on = (t ~= nil and t.fullscreen) or WAVEFORM_DEFAULT
  mineral.config.override({ tui = { waveform = { enabled = on } } })
end)

return {
  tui = { waveform = { enabled = WAVEFORM_DEFAULT } },
}
```

## tui.cover — 封面

| 字段                   | 默认     | 说明                                                                                                                                                              |
| ---------------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `protocol`             | `"auto"` | 图片协议：`"auto"` 启动时探测，zellij 等不支持图片显示的环境使用 halfblock；可指定 `"halfblocks"` / `"kitty"` / `"sixel"` / `"iterm2"`，Kitty 需要 POSIX 共享内存 |
| `http_timeout_secs`    | 30       | 单张封面下载超时,秒                                                                                                                                               |
| `debounce_ms`          | 32       | 列表停止滚动后，等待多少毫秒再处理高清封面；等待时显示预览图，预览图未就绪则留空                                                                                  |
| `download_workers`     | 12       | 同时下载封面的任务数                                                                                                                                              |
| `encode_workers`       | 2        | 同时编码终端图片的任务数                                                                                                                                          |
| `decode_pixels.width`  | 1024     | 解码目标宽度，像素，须大于零                                                                                                                                      |
| `decode_pixels.height` | 1024     | 解码目标高度，像素，须大于零                                                                                                                                      |

解码保持原图比例，选择宽高均达到目标的最低可用 JPEG 缩放档位，原图较小时不放大。档位可能高于配置尺寸，不再额外精确缩放。其他格式先完整解码再等比缩小。窗口或封面区域变化不重新解码；配置热更用于后续解码，已有缓存自然淘汰后更新。

`cache` 设置缓存容量。空间不足时清理最久未使用的内容；调小磁盘缓存容量不会立即删除文件。

| 字段       | 默认                      | 说明                                                       |
| ---------- | ------------------------- | ---------------------------------------------------------- |
| `disk`     | `4 * 1024 ^ 3`(4 GiB)     | 原始图片文件的磁盘缓存容量                                 |
| `image`    | `128 * 1024 ^ 2`(128 MiB) | 解码后高清图片的内存容量                                   |
| `preview`  | `16 * 1024 ^ 2`(16 MiB)   | 预览图的内存容量，按图片和目标尺寸缓存；高清图未就绪时显示 |
| `protocol` | `64 * 1024 ^ 2`(64 MiB)   | 终端协议图片的内存容量                                     |

三层内存缓存优先清理当前未显示的图片。正在显示的图片可暂时超过预算，离开屏幕后再回收。协议缓存按实际图片数据大小计算占用；Kitty 使用 RGB / RGBA 共享内存的大小，不重复计算解码原图或 base64 编码大小。

`kmeans` 控制封面取色：

| 字段                    | 默认         | 说明                                             |
| ----------------------- | ------------ | ------------------------------------------------ |
| `sample_dim`            | 64           | 取色采样边长，像素；64 对应约 4 千个像素         |
| `swatches`              | 6            | 提取颜色的数量上限，即聚类的 k 值                |
| `seed`                  | `0x5EEDC0DE` | 聚类随机种子；固定后，同一封面的取色结果保持一致 |
| `max_iter` / `converge` | 20 / 5.0     | 迭代上限 / 收敛阈值(Lab 空间)                    |
| `l_min` / `l_max`       | 8.0 / 92.0   | 取色的明度范围，Lab L；排除过黑或过白的像素      |
| `chroma_min`            | 8.0          | 丢弃近灰像素的彩度下限                           |
| `min_valid_pixels_pct`  | 5            | 过滤后像素占比低于此百分比时，改用全部像素取色   |

## tui.ambient — 全屏氛围背景

全屏背景使用封面提取的颜色，色斑缓慢移动，切歌时逐渐换成新封面的颜色。背景随进入全屏的动画淡入，不改变文字颜色。主题底色为 ANSI / indexed 色时不显示。

| 字段        | 默认   | 说明                                      |
| ----------- | ------ | ----------------------------------------- |
| `enabled`   | `true` | 是否显示氛围背景；关闭时逐渐淡出          |
| `intensity` | 0.4    | 封面颜色的混合比例，0–1；0 为主题底色     |
| `sigma`     | 0.2    | 色斑的高斯半径，相对屏幕尺寸              |
| `fade_ms`   | 5000   | 切歌 / 取色就绪时调色板渐变到新封面的时长 |

`vignette` 控制背景边缘的暗角：

| 字段       | 默认 | 说明                                |
| ---------- | ---- | ----------------------------------- |
| `strength` | 0.75 | 边缘变暗的强度，0–1；0 关闭         |
| `inner`    | 0.25 | 起始半径(到屏心相对距离,此内无暗角) |
| `outer`    | 0.75 | 暗角达到最大强度的半径              |

`drift` 控制色斑移动：

| 字段       | 默认   | 说明                                   |
| ---------- | ------ | -------------------------------------- |
| `enabled`  | `true` | 关闭后色斑位置不变，切歌时仍有颜色过渡 |
| `speed`    | 1.0    | 移动速度倍率；1 为各色斑设置的原速     |
| `sway_pct` | 20.0   | 色斑移动半径，占屏幕尺寸的百分比       |

`rotate` 控制色斑颜色沿色带从暗到亮、再从亮到暗循环变化。`drift` 控制位置，两者独立。

| 字段         | 默认   | 说明                                |
| ------------ | ------ | ----------------------------------- |
| `enabled`    | `true` | 关闭后，各色斑保持 `pos` 指定的颜色 |
| `cycle_secs` | 30.0   | 颜色往返变化的周期，秒              |

`pulse` 控制背景随音乐响度的变化。响度经过低通滤波、近期峰谷归一化和 gamma 调整，再通过主包络与瞬态包络控制变化速度。暂停或静音后按 `release_ms` 逐渐恢复。

| 字段               | 默认   | 说明                                                             |
| ------------------ | ------ | ---------------------------------------------------------------- |
| `enabled`          | `true` | 背景是否随响度变化                                               |
| `depth.intensity`  | 0.2    | 响度增大时，封面颜色混合比例的增量                               |
| `depth.sigma`      | 0.25   | 响度增大时，色斑半径的增大比例；不改变颜色深浅                   |
| `depth.brightness` | 0.05   | 响度增大时，色带采样位置向亮端移动的幅度                         |
| `depth.vignette`   | 0.1    | 响度增大时，暗角减弱的比例                                       |
| `attack_ms`        | 70     | 主包络上升时间，毫秒                                             |
| `release_ms`       | 420    | 主包络衰减时间，毫秒                                             |
| `gain_window_secs` | 4.0    | 响度归一化的峰谷跟踪窗口，秒                                     |
| `bass_cutoff_hz`   | 150.0  | 计算响度时的低通截止频率，Hz；0 为不滤波                         |
| `gamma`            | 2.6    | 归一化响度的 gamma；1 为线性                                     |
| `punch.gain`       | 0.4    | 瞬态包络强度；该包络立即上升、快速衰减，与主包络取较大值；0 关闭 |
| `punch.release_ms` | 160    | 瞬态包络衰减时间，毫秒                                           |

`anchors` 数组每项对应一个色斑，修改时整体替换。字段如下：

- `x` / `y`：初始位置，相对屏幕宽高，范围 0–1。
- `pos`：色带位置，0 为最暗色，1000 为最亮色。
- `speed_x` / `speed_y`：两轴角速度，弧度/秒；不同速度可形成非圆形轨迹。
- `phase_x` / `phase_y`：两轴初始相位。

默认五个色斑，具体位置见 `default.lua`。

## tui.copy — 复制菜单模板

`templates` 为 `y` 复制菜单添加自定义项，排在内置项之后。数组整体替换，默认为空。`template` 函数接收实体数据，返回要复制的文本；函数在 daemon 中执行，超时或报错时显示通知，不修改剪贴板。

| 字段       | 必填 | 说明                                                                                                                                                             |
| ---------- | ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `label`    | 是   | 菜单项显示名                                                                                                                                                     |
| `template` | 是   | `function(entity) -> string`,返回写入剪贴板的文本                                                                                                                |
| `key`      | 否   | 快捷字母；与内置项重复时优先触发自定义项；省略后用 `j` / `k` 选择、Enter 执行                                                                                    |
| `context`  | 否   | 适用的实体类型：`"song"`(默认,收 `mineral.Song`)/ `"playlist"`(收 `mineral.Playlist`,含 `songs`)/ `"album"`(收 `mineral.Album`)/ `"artist"`(收 `mineral.Artist`) |

```lua
copy = {
  templates = {
    { key = "f", label = "Copy full", template = function(s)
        return s.title .. " - " .. table.concat(s.artists, ", ")
      end },
  },
}
```

## tui.window_title — 窗口标题

终端窗口或标签页标题由 `segment` 数组按顺序拼接。`template` 用于播放和暂停，`idle` 用于没有播放歌曲时，`disconnected` 用于未连接 daemon 时。

| 字段                    | 默认                                                               | 说明                                         |
| ----------------------- | ------------------------------------------------------------------ | -------------------------------------------- |
| `enabled`               | `true`                                                             | 关闭则不写终端标题(不 push / pop 标题栈)     |
| `icons`                 | `{ playing = "⏸", paused = "▶", idle = "■", disconnected = "⚠" }`  | 四态状态图标(`{ icon = true }` segment 取用) |
| `template`              | `{ {icon=true}, {field="title"}, {field="artist", prefix=" — "} }` | 播放 / 暂停态的 segment 数组                 |
| `idle` / `disconnected` | `{ {icon=true}, {text="Mineral"} }`                                | 无在播 / 未连 daemon 态                      |

每个 segment 可以是：

- `{ icon = true }`：当前状态图标。
- `{ text = "..." }`：固定文本。
- `{ field = "...", prefix = "...", suffix = "...", format = "..." }`：播放信息，后三个字段可省略。字段为空时，整段连同前后缀一起省略。

`field` 支持 `title` / `artist` / `album` / `position` / `duration` / `source` / `lyric`。

`format` 仅用于 `position` 和 `duration`：`"clock"`（默认）显示 `mm:ss`，一小时起显示 `h:mm:ss`；`"seconds"` 显示秒数；也可用 `{ pattern = "{m}:{ss}" }` 自定义格式，支持 `{h}` / `{hh}` / `{m}` / `{mm}` / `{s}` / `{ss}`。

| `quality`         | `"lossless"`               | 下载音质,与播放音质相互独立                                |
| `dir`             | `nil`(= `~/Music/mineral`) | 导出目录,绝对路径                                          |
| `max_concurrent`  | `3`                        | 同时下载的歌曲数，至少为 1                                 |
| `tagging`         | `true`                     | 为下载和播放缓存文件写入标题、艺人、专辑、封面、歌词等标签 |
| `tagging_workers` | `4`                        | 同时写入标签的任务数；1 为串行                             |

## sources — 音乐源

每个音乐源对应一张子表。`netease` / `bilibili` 设置网络请求和徽标颜色，`mineral` 设置聚合收藏的徽标颜色和歌曲信息补全。`color` 的写法见[色值写法](#色值写法)。

`sources.netease` / `sources.bilibili`:

| 字段              | 默认(netease / bilibili)  | 说明                                                                 |
| ----------------- | ------------------------- | -------------------------------------------------------------------- |
| `timeout_secs`    | 100 / 100                 | 单次 API 请求超时,秒                                                 |
| `proxy`           | `false`                   | `false` = 不走代理;字符串 = 代理 URL(如 `"socks5://127.0.0.1:1080"`) |
| `max_connections` | 0                         | 到源的最大并发连接,0 = 不限                                          |
| `color`           | `"#9D2928"` / `"#FF8cB0"` | 来源徽标色(token 名 / `"#rrggbb"` / `{ ansi = ... }`)                |

`sources.netease.playlist_fetch` 控制歌单曲目的请求批次：

| 字段             | 默认  | 说明                                                                       |
| ---------------- | ----- | -------------------------------------------------------------------------- |
| `batch_size`     | `500` | 浏览歌单时每批覆盖的歌曲 ID 数量，以及每次歌曲详情请求的 ID 上限；须大于零 |
| `max_concurrent` | `3`   | 一个歌单内并发的歌曲详情请求数；须大于零                                   |

`sources.mineral`(聚合收藏源):

| 字段                      | 默认        | 说明                                 |
| ------------------------- | ----------- | ------------------------------------ |
| `color`                   | `"#2a6511"` | 来源徽标色                           |
| `backfill.chunk_size`     | 40          | 后台补全歌曲信息时，每批请求的歌曲数 |
| `backfill.max_concurrent` | 3           | 同时执行的歌曲信息请求数             |

各来源的 `curate_playlists` 函数可过滤、改名或重排该来源的歌单。设在 `sources` 表上的同名函数则处理合并后的所有来源歌单。

## queue — 队列变换

`transforms` 为队列操作菜单添加脚本操作，数组整体替换，默认为空。

`transform(queue, ctx)` 在 daemon 中执行，接收当前队列并返回新队列。`ctx.current` 是正在播放的下标，`ctx.selected` 是光标所在下标，没有选中项时为 `nil`。下标从 1 开始。返回的歌曲 ID 必须来自原队列，可以重复；包含外部歌曲 ID 时，整个操作被拒绝。

| 字段        | 必填 | 说明                                                 |
| ----------- | ---- | ---------------------------------------------------- |
| `label`     | 是   | 菜单项显示名                                         |
| `transform` | 是   | `function(queue, ctx) -> queue`,返回重排后的有序队列 |
| `key`       | 否   | 快捷字母；省略后通过菜单选择并执行                   |

## daemon — 后台运行参数

控制后台任务的执行间隔，修改后重启 daemon。

| 字段                        | 默认  | 说明                                                |
| --------------------------- | ----- | --------------------------------------------------- |
| `gapless_prefetch_ms`       | 10000 | 结束前多少毫秒开始准备下一首                        |
| `prev_restart_threshold_ms` | 3000  | `p` 键分界:进度超过此值回曲首,否则上一首            |
| `player_tick_ms`            | 20    | 播放核心后台循环间隔，毫秒                          |
| `session_save_secs`         | 15    | 定期保存播放进度的间隔，秒；切歌等操作会立即保存    |
| `heartbeat_secs`            | 180   | 状态心跳日志间隔,秒;daemon 与 TUI 各打一条供排查    |
| `report_interval_ms`        | 200   | 向系统媒体控件(MPRIS / Now Playing)上报进度的间隔   |
| `seek_threshold_ms`         | 1000  | 进度偏离线性预期超过此值判定为 seek(供媒体控件上报) |
| `download_speed_tick_ms`    | 150   | 下载测速刷新节流                                    |
| `channel_workers_per`       | 8     | 每个音乐源的后台并发任务数                          |

## script — 脚本运行时

| 字段                            | 默认 | 说明                                             |
| ------------------------------- | ---- | ------------------------------------------------ |
| `watchdog_instruction_interval` | 2000 | 检查脚本耗时的 Lua 指令间隔                      |
| `watchdog_soft_wall_ms`         | 100  | 回调超过此毫秒数时记录警告，继续执行             |
| `watchdog_hard_wall_ms`         | 1000 | 回调超过此毫秒数时中断本次调用，脚本仍可继续使用 |
| `hook_timeout_ms`               | 2000 | 拦截 hook 的超时时间，毫秒；超时后放行操作       |
| `spawn_max_concurrent`          | 8    | `mineral.spawn` 子进程并发上限;0 = 不限          |

## stats — 行为埋点

采集设置只影响之后的记录。`report` 设置统计范围，修改后也适用于已有记录。使用 `mineral stats report` 查看报表。

| 字段                     | 默认     | 说明                                                                                        |
| ------------------------ | -------- | ------------------------------------------------------------------------------------------- |
| `level`                  | `"full"` | 采集级别：`"off"` 不记录 / `"core"` 记录播放和会话 / `"full"` 记录全部交互                  |
| `collect`                | `{}`     | 按事件开关采集（`kind = true / false`）；`plays` / `sessions` 只能通过 `level = "off"` 关闭 |
| `search_queries`         | `"raw"`  | 搜索词:`"raw"` 原文 / `"hashed"` 不可逆散列(保次数去重,丢原文)/ `"off"` 不记                |
| `exclude_sources`        | `{}`     | 不记录的来源，例如 `{"plugin-dev"}`                                                         |
| `session_gap_minutes`    | 30       | 播放活动间隔超过此值(分钟)切分新收听会话                                                    |
| `retention_days`         | `false`  | 记录保留天数;`false` = 永久,正整数 = 保留 N 天                                              |
| `report.min_listen_secs` | 30       | 有效播放阈值:听不足此秒数不计入 top 榜 / 完播率(仍保留原始记录)                             |
| `report.top_limit`       | 10       | 各 top 榜长度(CLI `--top` 可再覆盖)                                                         |
